# Online Video Downloader

## Description
Online-Downloader is a yt-dlp tool designed to simplify the process of downloading files from the internet. Seamless downloading anytime via interactive prompts in python.
###
Visit the yt-dlp [repo](https://github.com/yt-dlp/yt-dlp)
## Features
- Support for multiple file formats.
- Easy-to-use interface with prompts.
- Fast and reliable downloads.

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/abnerj99/online-downloader-app
    ```
2. Navigate to the project directory:
    ```bash
    cd online-downloader-app
    ```
3. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## Usage Guide
- Requires Most Recent yt-dlp version!

1. Navigate to online-downloader-app directory.
   ```bash
    cd online-downloader-app
    ```
2. Start the application:
    ```bash
    python3 main.py
    ```
3. Follow the on-screen instructions to start downloading files.
